재단 마케팅 자료 참고

재단에서 배포한 검사 안내서와 서비스 소개 자료를 첨부하세요. 자료는 이 브라우저에서 처리하며 파일 자체를 외부 서버에 업로드하지 않습니다.

아직 첨부된 자료가 없습니다.

추출한 내용은 PDF 제안서의 핵심 검사·서비스 카드와 제안 포인트 구성에 사용됩니다. 원문을 별도 부록으로 붙이지 않습니다.

위 항목을 입력한 뒤 ‘제안서 초안 만들기’를 누르세요.

생성되는 문서는 수정 가능한 초안입니다. 실제 검사 가능 여부, 가격 및 계약 조건은 내부 확인 후 사용해 주세요.

숙성영업 관리

추후 재방문하거나 연락할 거래처와 영업 진행 상황을 기록합니다.

기록은 현재 브라우저에 저장됩니다. 브라우저 데이터 삭제나 기기 변경 시 기록이 사라질 수 있으므로 주기적으로 백업해 주세요.

시장조사

지역과 조사 주제를 선택해 공개 웹 정보를 검색합니다.

검색 결과는 외부 검색 사이트에서 확인합니다. 이 메뉴는 검색을 실행하는 기능이며, 조사 결과를 자동으로 수집하거나 검증된 시장조사 보고서로 만들어 주는 기능은 아닙니다.

조사 시 확인할 항목

① 의료기관명과 주소
② 개원 또는 채용 시점
③ 진료과목 및 검진 여부
④ 현재 거래 가능성
⑤ 방문 우선순위와 후속 조치

영업 우선순위 설정

신규 개원 예정 기관, 검사 항목 확대 가능성이 있는 의원, 거래 전환 가능성이 있는 기관부터 확인하고 조사 결과를 숙성영업 관리에 등록하세요.
